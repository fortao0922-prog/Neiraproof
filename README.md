# Бот Лаборатории Нейры · @neiraproof_bot

Воронка «ЛАБ»: ссылка `t.me/neiraproof_bot?start=<код>` → проверка подписки на канал → выдача PDF.

## Лид-магниты
| Код | Материал | Пост |
|---|---|---|
| `lab50` | 50 промптов без воды | № 001 |
| `voda10` | 10 фраз против воды | № 002 |
| `video4` | Чек-лист: как проверить, что видео сделал AI | № 003 |
| `foto` | 5 промптов для фото товара | № 012 |

## Добавить новый
PDF кладётся в корень репозитория, запись — в `materials.json`. После коммита пересобрать бота в BotHost.

## Настройки (переменные окружения BotHost)
`BOT_TOKEN`, `CHANNEL`, `ADMIN_IDS`, по желанию `DEFAULT_CODE` (по умолчанию `lab50`).
